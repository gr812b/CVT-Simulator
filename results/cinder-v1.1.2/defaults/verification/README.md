# Shared verification operating cases

`operating_cases.json` is the canonical release-scoped vocabulary of controlled
verification states and search recipes.

It owns fixed-boundary bench ranges, gross tangential contact requests, both
overall rotation signs, free-shift directions, static/boundary recipes, and
deterministic reproduction anchors for the rare `secondary_slip_plus` and
`both_slip_mp` classes.

The rare anchors are not pre-approved solutions. Every consuming study must
still classify the state through production mechanics, apply its own physical
checks, run the continuation, and inspect exact successor states.
