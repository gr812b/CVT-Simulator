# WebPlotDigitizer source bundle

This directory preserves the raw manual digitization provenance for the Ballew
benchmark. The five data/project files here are source evidence and should not
be edited in place:

- `input_rpm.csv` — Figure 41 input/primary RPM trace;
- `output_rpm.csv` — Figure 41 output/secondary RPM trace;
- `axial_force.csv` — Figure 45 undamped primary axial-force trace;
- `rpms_ballew.json` — WebPlotDigitizer project for Figure 41;
- `axial_force_ballew.json` — WebPlotDigitizer project for Figure 45.

The CSVs are the headerless two-column exports produced by WebPlotDigitizer.
Benchmark-ready files one directory up are generated by
`../prepare_reference_data.py`.

## Reopening the digitization

1. Open WebPlotDigitizer.
2. Load `../source/Ballew_2015_thesis.pdf`.
3. Navigate to:
   - Figure 41 — printed p. 58 / PDF p. 68;
   - Figure 45 — printed p. 62 / PDF p. 72.
4. Load the corresponding project JSON.
5. Inspect the stored calibration and clicked points over the source figure.

The Figure 41 project contains the input RPM dataset and an `output_rpm`
dataset. The Figure 45 project contains the axial-force dataset.

## Recorded source-data checks

The archived raw point sets were checked against the project JSON values and
against the plotted thesis figures:

| Trace | Points | Digitized time range | Digitized value range |
|---|---:|---:|---:|
| Figure 41 input RPM | 113 | 0.110375–4.988962 s | 2444.01–2515.32 rpm |
| Figure 41 output RPM | 64 | 0.110375–4.988962 s | 1133.70–1271.87 rpm |
| Figure 45 primary force | 211 | 0.095541–5.000000 s | 2113.21–2710.85 N |

Raw-data quirks intentionally preserved:

- neither Figure 41 trace is given an artificial `t=0` point;
- raw Figure 45 has duplicate time coordinates at approximately `0.477707`,
  `2.468153`, `3.789809`, and `4.490446 s`;
- the preparation script averages only those duplicate force values and adds the
  explicit A6 zero-time hold required by force replay.

No smoothing, resampling, or curve fitting is applied.
