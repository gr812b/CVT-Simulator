# Full-machine reconstruction — deferred

Before a machine-specific CINDER Sidewinder run is treated as a result, source or measure: movable-secondary MOI, effective helix radius, spring properties, pulley travel/radii, primary clutch actuation, driveline/track inertia, engine torque curve, and preferably one measured secondary-speed or sheave-position transient. The current component-sensitivity case is deliberately more defensible than a fully invented machine model.
