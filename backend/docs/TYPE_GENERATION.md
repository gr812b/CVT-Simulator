# Contract type generation

The API has two distinct type sources:

1. **OpenAPI** generated by FastAPI types endpoint envelopes: run lifecycle,
   metadata envelopes, study requests, and API errors.
2. **CINDER JSON Schema** types the full nested version-one simulation document.

This avoids reflecting Python mechanics classes into Pydantic and avoids
retyping CINDER's saved-document shape in the backend.

```bash
python -m app.scripts.export_contract_artifacts --output-dir generated
npx openapi-typescript generated/openapi.json -o ../frontend/src/generated/api.ts
npx json2ts generated/cinder_simulation_case.schema.json -o ../frontend/src/generated/cinder-contract.ts
```

The exact JSON-schema-to-TypeScript command can vary by chosen tool. The key
contract is that generated document types are driven by CINDER's public schema,
not by backend reflection or frontend parameter mappings.
