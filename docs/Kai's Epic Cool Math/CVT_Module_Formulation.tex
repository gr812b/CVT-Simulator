\section{Overview}\label{sec:overview}

\subsection{Purpose of This Document}

This document presents a complete dynamic derivation of a continuously
variable transmission (CVT) system model. The goal is to develop a
physically consistent set of governing equations that describe:

\begin{itemize}
    \item Rotational dynamics of the primary and secondary assemblies,
    \item Axial shift dynamics of the primary sheave,
    \item Belt traction and torque transfer,
    \item Slip behavior under torque saturation,
    \item Coupled vehicle longitudinal response.
\end{itemize}

The resulting formulation provides a structured, state-based model
suitable for numerical simulation and performance analysis.

\subsection{Scope}

This document focuses on the mechanical modeling of the CVT system.
It includes force balances, torque transfer mechanisms, and dynamic
coupling between rotational and axial motion.

The following are outside the scope of this document:

\begin{itemize}
    \item Thermal modeling,
    \item Long-term wear or material degradation,
    \item Detailed tribological contact mechanics,
    \item Multi-body vehicle dynamics beyond one-dimensional motion.
\end{itemize}

All assumptions limiting model fidelity are formally defined in
\Sec{sec:assumptions}.

\subsection{Expected Background Knowledge}

The reader is expected to be familiar with:

\begin{itemize}
    \item Newton’s laws of motion,
    \item Basic rigid-body rotational dynamics,
    \item Linear spring models,
    \item Gear ratios and torque multiplication,
    \item Basic algebra and differential equations.
\end{itemize}

Prior familiarity with state-space modeling or numerical integration
is not assumed. Relevant concepts are introduced where required.

\subsection{Conceptual Overview of a CVT}

A continuously variable transmission (CVT) transmits torque between
an engine and drivetrain using a belt or chain running between two
variable-diameter pulleys.

Each pulley consists of conical sheaves whose axial separation determines
the effective belt radius. As the primary sheave shifts axially, the
effective radius changes, which in turn modifies the transmission ratio.

Unlike discrete gearboxes, a CVT provides a continuously varying ratio.
Torque transfer is governed by belt traction, normal clamping forces,
and frictional interaction between the belt and pulley faces.

When transmitted torque exceeds traction capacity, slip occurs.
Accurately modeling both stick and slip regimes is essential for
predicting performance.

\subsection{Modeling Approach}

The system is modeled using a minimal set of dynamic state variables,
defined in \Sec{sec:state}. All other quantities are derived algebraically
from these states.

The derivation proceeds as follows:

\begin{itemize}
    \item Governing physical laws are defined (\Sec{sec:principles}),
    \item Kinematic relationships between pulley geometry and ratio are derived,
    \item Axial and radial force models are constructed,
    \item Belt traction limits are formulated,
    \item Rotational and axial equations of motion are assembled,
    \item Slip behavior is incorporated.
\end{itemize}

The final result is a coupled nonlinear dynamic system
suitable for time-domain simulation.


\section{Notation and Conventions}\label{sec:notation}
\subsection{Coordinate and Sign Conventions}\label{sec:sign}

A consistent set of coordinate directions and sign conventions
is adopted throughout this document. All equations follow these conventions.

\subsubsection{Vehicle Longitudinal Direction}

The vehicle is modeled as a one-dimensional system moving along a
single longitudinal axis.

\begin{itemize}
    \item Positive direction ($+x$) is defined as forward vehicle motion.
    \item Vehicle velocity $v > 0$ corresponds to forward motion.
    \item Resistive forces (rolling resistance, aerodynamic drag, grade load)
    act in the negative ($-x$) direction.
\end{itemize}

\paragraph{Incline Angle}

If terrain grade is considered, the incline angle $\alpha$ is defined as:

\begin{itemize}
    \item $\alpha > 0$ for uphill motion.
    \item $\alpha = 0$ for level ground.
\end{itemize}

The gravitational component acting along the longitudinal axis is:

\[
F_{\text{grade}} = m g \sin\alpha
\]

This modifies the longitudinal load only and does not introduce
additional spatial dimensions into the model.

\subsubsection{Rotational Sign Convention}

All angular velocities follow the same convention:

\begin{itemize}
    \item Positive angular velocity corresponds to forward vehicle motion.
    \item Primary and secondary pulleys are defined such that
    $\omega_p > 0$ and $\omega_s > 0$ produce forward belt motion.
    \item Applied engine torque is positive when it increases $\omega_p$.
\end{itemize}

Reaction torques opposing motion are therefore negative.

\subsubsection{CVT Axial Direction}

The axial direction of the primary pulley is defined along its shaft axis.

\begin{itemize}
    \item Positive axial displacement $s > 0$ corresponds to increasing
    primary effective radius.
    \item Increasing $s$ therefore corresponds to an upshift
    (decreasing overall CVT ratio).
\end{itemize}

The axial velocity $\dot{s}$ follows the same sign convention.

\subsubsection{Radial Direction}

Radial direction is defined perpendicular to the pulley axis,
measured outward from the center of rotation.

\begin{itemize}
    \item Radial forces $F_r > 0$ act outward from the pulley center.
    \item Belt normal forces are treated as positive when compressive.
\end{itemize}

\subsubsection{Slip Velocity Sign Convention}

Slip velocity between belt and pulley is defined as:

\[
v_{\mathrm{slip}} = r_p(s)\omega_p - r_s(s)\omega_s
\]

\begin{itemize}
    \item $v_{\mathrm{slip}} > 0$ indicates the primary surface speed
    exceeds the secondary surface speed.
    \item $v_{\mathrm{slip}} = 0$ corresponds to no-slip contact.
\end{itemize}

\section{Modeling Assumptions}\label{sec:assumptions}

The following assumptions define the modeling scope and physical idealizations
used in the CVT dynamic formulation. These assumptions establish the limits
within which the derived equations remain valid.

% ======================================================
\subsection{Material and Structural Idealizations}

\begin{assumptionblock}{assump:material_constancy}{Constant Material Properties}
Material properties of structural components are treated as constant.
No temperature-dependent material variation is modeled.
Thermal effects are not solved as part of this system.
\end{assumptionblock}

\begin{assumptionblock}{assump:rigid_components}{Rigid Structural Components}
All structural components (pulleys, shafts, housing) are modeled as rigid bodies.
Elastic deformation under operational loading is neglected.
The belt is assumed axially rigid (no longitudinal stretch),
while still conforming geometrically around pulleys.
\end{assumptionblock}

\begin{assumptionblock}{assump:no_wear}{Negligible Wear and Surface Evolution}
Component wear, belt degradation, and pulley surface evolution
are neglected.
The model represents short-term operational behavior.
\end{assumptionblock}

% ======================================================
\subsection{Contact and Friction Modeling}

\begin{assumptionblock}{assump:ideal_friction}{Idealized Belt--Pulley Friction Law}
Belt traction is modeled using a simplified friction law
(e.g., Coulomb friction with a capstan formulation and
an explicit stick--slip transition rule).
Microscopic contact mechanics, rubber hysteresis,
lubrication films, and detailed Stribeck effects
are not explicitly modeled.
\end{assumptionblock}

\begin{assumptionblock}{assump:constant_friction}{Constant Effective Friction Coefficient}
The belt--pulley coefficient of friction is treated as constant.
It does not evolve with temperature, wear, or surface conditioning.
\end{assumptionblock}

\begin{assumptionblock}{assump:uniform_contact}{Uniform Contact Distribution}
Contact pressure and traction over the pulley wrap angle
are treated as effectively uniform or averaged.
Localized edge loading and non-uniform stress distributions are neglected.
\end{assumptionblock}

% ======================================================
\subsection{Geometric and Kinematic Idealizations}

\begin{assumptionblock}{assump:axis_alignment}{Perfect Axis Alignment}
Primary and secondary pulley axes are assumed perfectly aligned.
Misalignment, shaft eccentricity, and geometric runout are neglected.
\end{assumptionblock}

\begin{assumptionblock}{assump:constant_belt_length}{Constant Belt Length}
The belt length is treated as constant.
Permanent creep and progressive elongation are not modeled.
Effective pulley radii are determined solely from geometry
and belt-length constraints.
\end{assumptionblock}

% ======================================================
\subsection{Dynamic and Inertial Modeling}

\begin{assumptionblock}{assump:lumped_inertia}{Lumped Inertia Representation}
Rotational inertias of the engine, pulleys, drivetrain,
and wheels are represented as lumped equivalent inertias.
Distributed shaft flex and torsional compliance are neglected.
\end{assumptionblock}

\begin{assumptionblock}{assump:no_vibration}{Negligible Vibrational Effects}
High-frequency vibrational effects, structural resonances,
and drivetrain oscillations are neglected.
The model captures dominant rigid-body dynamics only.
\end{assumptionblock}

\begin{assumptionblock}{assump:no_parasitic_losses}{Negligible Parasitic Friction}
Frictional losses in non-critical components
(e.g., bearings, seals, auxiliary shafts)
are neglected.
Only friction directly relevant to belt traction
and CVT torque transfer is modeled.
\end{assumptionblock}

% ======================================================
\subsection{Environmental and Operational Scope}

\begin{assumptionblock}{assump:gravity_internal}{Negligible Gravitational Influence on CVT Internals}
Gravitational forces acting on CVT internal components
are negligible relative to centrifugal and contact forces
at operating speeds.
\end{assumptionblock}

\begin{assumptionblock}{assump:full_throttle_model}{Full-Throttle Engine Model}
The engine is modeled using a prescribed full-throttle torque curve.
Load feedback modifies engine speed dynamically,
but part-throttle dynamics and throttle transients
are not explicitly modeled.
\end{assumptionblock}

\section{System State Definition}\label{sec:state}

The dynamic behavior of the CVT system is described using a set of
\emph{state variables}. A state variable is a quantity whose future value
depends on its current value and its time derivative. In numerical
simulation, state variables are the quantities that are directly
integrated forward in time at each timestep.

All other quantities in the model (e.g., torque transfer, CVT ratio,
belt forces) are computed algebraically from these states.

\subsection{State Vector}

\bigeq{eq:state-vector}{State Vector}{
\vect{x}(t) =
\begin{bmatrix}
\omega_p \\
\omega_s \\
s \\
\dot{s}
\end{bmatrix}
}

where:

\begin{itemize}
    \item $\omega_p$ is the angular speed of the primary pulley 
    (\si{\radian\per\second}).

    \item $\omega_s$ is the angular speed of the secondary pulley 
    (\si{\radian\per\second}).

    \item $s$ is the axial shift position of the primary sheave 
    (\si{\meter}).

    \item $\dot{s}$ is the axial shift velocity 
    (\si{\meter\per\second}).
\end{itemize}

\subsection{Why These Are the State Variables}

These four variables represent the independent dynamic degrees of freedom
of the CVT system:

\begin{itemize}
    \item The primary pulley rotation ($\omega_p$) evolves according to
    applied engine torque and belt reaction torque.

    \item The secondary pulley rotation ($\omega_s$) evolves according to
    belt torque and external load torque.

    \item The axial shift position ($s$) evolves according to the
    balance of axial forces between the primary and secondary assemblies.

    \item The axial velocity ($\dot{s}$) is required because axial motion
    follows a second-order differential equation.
\end{itemize}

This will be made clear in the following derivations in later sections (TODO: MAKE BETTER). Removing any of these variables would eliminate an independent dynamic
degree of freedom from the model.

\subsection{Numerical Integration Perspective}

At each simulation timestep $\Delta t$, the following updates occur:

\begin{itemize}
    \item $\omega_p$ is updated using its angular acceleration.
    \item $\omega_s$ is updated using its angular acceleration.
    \item $s$ is updated using $\dot{s}$.
    \item $\dot{s}$ is updated using axial acceleration.
\end{itemize}

Thus, the state vector evolves according to differential equations
derived in later sections.

All other model quantities — including CVT ratio, belt slip velocity,
radial forces, and torque capacity — are computed directly from the
current values of $\omega_p$, $\omega_s$, and $s$.
