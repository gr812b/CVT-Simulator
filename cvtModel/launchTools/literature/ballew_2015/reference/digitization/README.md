# WebPlotDigitizer source bundle

This directory preserves the **raw manual digitization provenance** for the
Ballew benchmark. Do not edit these five files in place:

- `input_rpm.csv` - Figure 41 input/primary pulley RPM trace.
- `output_rpm.csv` - Figure 41 output/secondary pulley RPM trace.
- `axial_force.csv` - Figure 45 undamped primary axial-force trace.
- `rpms_ballew.json` - WebPlotDigitizer/Automeris project for Figure 41.
- `axial_force_ballew.json` - WebPlotDigitizer/Automeris project for Figure 45.

The CSV files are the headerless two-column exports produced by
WebPlotDigitizer. Benchmark-ready files one directory up are generated by
`../prepare_reference_data.py`; the raw exports remain untouched.

## Reopening and verifying the digitization

WebPlotDigitizer is the browser tool at **automeris.io/WebPlotDigitizer**.

1. Open WebPlotDigitizer.
2. Load the bundled `../source/Ballew_2015_thesis.pdf` (the exact PDF used for this benchmark).
3. Navigate to the source figure:
   - Figure 41: printed thesis p. 58 / PDF page 68.
   - Figure 45: printed thesis p. 62 / PDF page 72.
4. Load the matching project JSON:
   - Figure 41 -> `rpms_ballew.json`
   - Figure 45 -> `axial_force_ballew.json`
5. The stored axis calibration and clicked data points should appear over the
   figure. Toggle/select the datasets to inspect the traced points.

The Figure 41 project contains the input RPM dataset (left at the original
`Default Dataset` name) and the `output_rpm` dataset. The Figure 45 project
contains the axial-force dataset.

## Sanity check recorded 2026-08-12

The raw CSV point sets were checked against the values stored in the two
project JSON files and matched exactly:

| Trace | Points | Digitized time range | Digitized value range |
|---|---:|---:|---:|
| Figure 41 input RPM | 113 | 0.110375-4.988962 s | 2444.01-2515.32 rpm |
| Figure 41 output RPM | 64 | 0.110375-4.988962 s | 1133.70-1271.87 rpm |
| Figure 45 primary force | 211 | 0.095541-5.000000 s | 2113.21-2710.85 N |

The traces were also visually checked against the PDF figures. Their gross
shape, extrema, and time evolution agree with the published plots.

### Raw-data quirks intentionally preserved

- The published curves do not quite begin at `t=0`, so neither Figure 41 raw
  trace has an artificial zero-time point.
- The raw Figure 45 export has four exact duplicate time coordinates where a
  near-vertical segment was clicked twice in the same pixel column:
  `0.477707`, `2.468153`, `3.789809`, and `4.490446 s`.
- These are not errors in the archived source files. The preparation script
  averages only the duplicated force values at each identical time so the
  replay table is a single-valued function.
- For the required force input only, the prepared replay adds `t=0` by holding
  the first visible Figure 45 force value backward from `0.095541 s`. This
  small unsupported interval is explicitly Reconstruction A6 and is not
  silently extrapolated.

No smoothing, resampling, or curve fitting is applied.
