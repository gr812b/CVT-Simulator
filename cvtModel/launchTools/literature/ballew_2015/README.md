# Ballew 2015 benchmark

CINDER reconstruction of the five-second **simulated vehicle-acceleration** case in Brian G. Ballew, *Investigation Of A Numerical Algorithm For A Discretized Rubber-Belt Continuously Variable Transmission Dynamic Model And Techniques For The Measurement Of Belt Material Properties* (M.S. thesis, University of Arkansas, 2015).

This is a **model-to-model benchmark**, not a road or dyno test. Ballew applies a fixed `18 N m` engine torque and fixed `2000 N` secondary axial force, while the secondary shaft load is generated by his simulated ATV/vehicle model.

Two complementary comparisons are retained:

1. **Force replay:** Figure 45 is imposed on CINDER. This asks how the two plant models respond to the same primary clamp history.
2. **Closed loop:** Ballew's published PI + feed-forward gains are reconstructed around unchanged CINDER, and Figure 45 becomes an output alongside Figure 41. This asks whether the same controller objective/parameters produce comparable clamp demand and shaft response on the two different plants.

Neither case tunes CINDER physics or controller gains to the paper curves.

Published inputs are transcribed in `constants.py`. Every non-published or ambiguous bridge into CINDER is registered in `RECONSTRUCTION.md` and referenced from code where it is applied.

The exact thesis PDF used for this reconstruction is archived at `reference/source/Ballew_2015_thesis.pdf`, with a SHA-256 provenance check in the runner. Source locations: Table A1 (printed p. 69 / PDF p. 79), Table B1 (printed p. 70 / PDF p. 80), Figure 39 (printed p. 54 / PDF p. 64), Figure 41 (printed p. 58 / PDF p. 68), and Figure 45 (printed p. 62 / PDF p. 72).

Scaffold prepared against `CVT-Simulator` `develop` at `ff3590e93624c98c75c9882723b94ba0516d792d`.

## What is reconstructed now

### Belt

Ballew's transient algorithm is a one-dimensional nodal belt model. The benchmark identifies that nodal path with CINDER's effective/cord-line path and uses Ballew's own Figure 39 dimensions for CINDER's equivalent smooth load-carrying section:

- height: `0.30 in`;
- outer/top width: `1.18 in`;
- inner/bottom width: `1.05 in`;
- cord/neutral line: `0.25 in` above the bottom, or `0.05 in` below the outer surface.

Figure 39 is explicitly Ballew's minimum section used for bending inertia, **not the literal cogged belt envelope**. It is used here because it is the source-native smooth trapezoid that provides the geometry CINDER requires. Cogs/ribs are not recreated.

Ballew's published `0.8636 m` nodal belt length is preserved at the effective path. CINDER's outer-surface length is therefore offset by the constant cord depth,

`L_outer = L_Ballew + 2*pi*d_cord`.

The resulting equivalent-section density is chosen so `rho*A*L_outer = 1.000 kg` exactly. This is an **effective mass-preserving density**, not a claim about the physical material density of the Gates belt.

Ballew reports that his material tests used a Gates G-Force `26C3596`, but the Chapter 5 numerical belt constants are kept authoritative for this benchmark; current/commercial belt dimensions are not substituted into the baseline.

### Clamp force and shift inertia

Ballew does not integrate a movable-sheave axial equation of motion. At each pulley he searches the uncompressed radius until the summed belt axial reaction matches the applied clamp force.

The current CINDER architecture can reproduce the **absence of movable-sheave inertia** cleanly: primary and secondary axial inertial reactions contain only their literal moving-sheave masses, so both are set to zero for this benchmark. This does not make CINDER's global shift coordinate equivalent to Ballew's distributed radial-migration/contact calculation; that remaining difference is part of the model-to-model comparison. With no helix, CINDER's local axial rows therefore reduce to algebraic clamp-force balance, `F_p - N_p/(2 tan beta) = 0` and `F_s - N_s/(2 tan beta) = 0`, rather than a fictitious sheave acceleration equation.

Ballew also has no primary disengagement interval in this Chapter 5 case. CINDER now represents that topology directly by allowing `deadzone_shift = lower_stop_shift = 0`: a **zero-width deadzone / always-engaged CVT**. The shared lower boundary is the engaged low-ratio seat, and the operating graph does not create a neutral transition there. No artificial epsilon-sized deadzone is introduced merely to satisfy the hybrid dispatcher.

The `1 kg` belt is **not** removed from the dynamics. CINDER retains belt transport/radial inertia in its reduced closed-belt equations; Ballew retains the corresponding dynamics explicitly through his distributed belt nodes. This is a model-form difference to compare, not something to tune away.

### Initial state

The exact Table B1 shaft speeds are used: `2500 rpm` primary and `1136 rpm` secondary. Their ratio is `2.200704...`; the separately listed `2.2` is treated as rounded. The compatible initial shift is solved from those exact speeds and the reconstructed belt geometry, with zero initial shift rate.

## Friction convention translation

Ballew's Table A1 values `mu_s=0.55`, `mu_k=0.40` are retained verbatim as source data, but they cannot be copied numerically into CINDER's reduced `lambda = Q/N` contact law. Ballew applies `mu F_Z` at each node while his in-plane radial reaction is `F_R = 2 F_Z tan(beta)`. The benchmark therefore preserves gross tangential capacity with

`lambda = mu / (2 tan(beta))`,

which at `beta=15 deg` gives `lambda_s=1.026313972...` and `lambda_k=0.746410162...`. This is a benchmark convention bridge, not a fitted friction change and not a claim that CINDER's scalar contact reproduces Ballew's 2-D node friction. See A10.

### Low-ratio boundary singularity found by the corrected case

The first run with the translated traction values exposed an exact rank-deficiency during LSODA event localization near the low-ratio seat. This was traced to the geometry accessor choosing deadzone-side `dr/ds = 0` at `s == deadzone_shift` even though the active mode was engaged. Ballew's zero-width deadzone and zero moving-sheave masses made the mistake an exact missing `s_ddot` column. CINDER now uses explicit engaged-side one-sided derivatives for engaged snapshots while retaining deadzone-side derivatives in the separate deadzone model. No Ballew parameter or CINDER force law was changed. See `SINGULARITY_DIAGNOSIS.md`.


### Contact-transition release at unilateral stops

A second benchmark-driven hybrid bookkeeping defect was exposed by the full A11 run. A contact
mode change at a low-ratio seat or upper stop can instantaneously change the recovered unilateral
reaction from compressive to tensile. The transition resolver now checks the successor contact branch
at the same event time and releases the stop immediately if it would have to pull. This changes no
force law or physical parameter; it only prevents an inadmissible constrained mode from surviving a
discrete contact-topology change. See `SINGULARITY_DIAGNOSIS.md`.

## Running the corrected force-replay comparison

The benchmark is now wired through CINDER's normal composed hybrid path:

`CVTAssemblySpec -> MechanicalCVTPlant -> ComposedCVTHybridSystem -> integrate_hybrid`.

From `cvtModel/`:

```powershell
python launchTools/literature/ballew_2015/run_comparison.py
```

The default headline run is five seconds with LSODA, `rtol=1e-7`, `atol=1e-9`,
`max_step=1e-3 s`, and solver-native dense output retained. Figure 41 error
metrics are evaluated by asking the dense solution for CINDER's state at the
**exact native digitized timestamps**. The paper traces are not resampled for
primary/secondary RPM metrics. A derived ratio trace uses the sorted union of
the two visible Figure 41 time sets, with only linear interpolation between
points of the opposite reference trace.

The default output directory is `results/force_replay/`; see `results/README.md`.
If the full five-second solve completes, the runner writes comparison/diagnostic PNGs,
uniform CINDER trace data, native-time comparison CSVs, a hybrid transition log,
`metrics.json`, and a compact `summary.md`. If unchanged CINDER instead reaches an
unsolved/singular closure before the paper traces become visible, the runner preserves
that outcome as `termination.json`, `partial_trace.csv`, and a partial diagnostic plot
rather than changing the translated friction values or the plant. Use `--audit-only` to validate the reconstruction without
integrating, or `--no-plots` for data-only output.

The result is intentionally an **untuned force-replay comparison**. In particular A1/A9 are
not adjusted to improve Figure 41 agreement. Once this comparison has been run
and inspected, the remaining work is numerical convergence and explicit
reconstruction sensitivities, not more hidden fitting.

## Running the closed-loop controller comparison

From `cvtModel/`:

```powershell
python launchTools/literature/ballew_2015/controller_reconstruction.py
python launchTools/literature/ballew_2015/run_closed_loop_comparison.py
```

Ballew publishes `Kff=1.2`, `Kp=5`, `Ki=75` and the 2500-rpm objective, but not the complete controller equation. The reconstruction audit uses the digitized Figure 41/45 traces only to identify the PI error sign/units after algebraically cancelling any constant feed-forward/bias; no gains are fitted back into the controller. The headline A11 controller uses `e = primary_rpm - 2500`, `Fff = 1.2*2000 = 2400 N`, zero initial integral, and no unpublished saturation/anti-windup.

If this controller cannot carry unchanged CINDER through the full five-second interval, the runner writes the failure and a reproducible partial trajectory instead of modifying gains or CINDER physics to continue.

### Stick/slip zero crossings

The benchmark uses CINDER's standard engaged-contact hybrid switching; it does
not force a contact regime to match Ballew.  At a kinetic slip-speed zero
crossing CINDER first attempts re-stick with its configured positive hysteresis
reserve.  If that reserve is not yet available, it next tests direction-consistent
kinetic continuation.  If neither kinetic direction can accelerate away from
zero, the reserve is not allowed to create a nonphysical gap in the mode graph:
the same topology-tightening stick candidate is retried against the actual
static-capacity/exit margin.  Only if that physical stick candidate is also
inadmissible may the contact transition terminate.  This fallback changes no
friction coefficient and is not a Ballew calibration.

### Ballew near-zero friction difference

Ballew Section 3.5 does not use the same exact-zero hybrid contact rule as CINDER. For each compressed belt node, Ballew uses kinetic Coulomb friction when `|v_rel| >= v_min`, with the published `v_min = 0.02 m/s`. Below that threshold the node either uses static friction to cancel the remaining tangential force, or, when that demand exceeds static capacity, an "impending motion" branch at `mu_s F_z`. Thus the source model has a finite near-zero transition layer.

This threshold is **not** silently copied into CINDER's gross pulley-contact tolerances. After the ordinary re-stick, kinetic-continuation, and physical-limit stick checks fail, CINDER now tests the previously missing simultaneous complementarity exchange in which the zero-crossing contact sticks while the previously sticking contact releases into an outgoing kinetic branch. A mixed exchange is preferred over both-slip, and every candidate must pass the same closure, static-capacity, normal-force, and outgoing-direction checks. This path acts only where the previous mode graph had no successor, so it cannot pre-empt an already-valid ordinary transition.

If even those expanded successors fail, the transition metadata reports the mechanics of the wider candidate set: stick--stick, both directions of the current slipping topology, the simultaneous swap of which pulley is slipping, and both-slip candidates. Those diagnostics distinguish an incomplete successor set from a genuine model-form difference before any Ballew-specific near-zero sensitivity is introduced.
